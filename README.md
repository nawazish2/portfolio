# Portfolio

A modern, responsive portfolio built with Next.js showcasing my work as a Full Stack Developer.

## Tech Stack

- **Frontend:** Next.js 16, React, Tailwind CSS, Framer Motion
- **UI Components:** Lucide React, next-icons
- **Fonts:** Space Grotesk, Bebas Neue (via next/font)
- **Deployment:** Vercel

## Features

- Dark/Light theme toggle
- Animated sections with Framer Motion
- Responsive design for all devices
- Real-time project previews
- Contact form with API integration
- SEO optimized metadata

## Sections

- **Hero** - Introduction with animated social links
- **About** - Skills and tech stack
- **Projects** - Portfolio projects with live previews
- **Contact** - Contact form and social links
- **Blog** - Link to Hashnode blog

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
